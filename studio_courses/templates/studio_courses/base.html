{% extends "studio/base.html" %} {% load breadcrumbs static %} {% comment %} The design system shell for the Studio Courses pages (issue #179). It extends studio/base.html rather than repeating it, for the reason that base gives: these are ~15 more near-identical staff pages, and the admin patterns they need — the data table, the filter bar, the actions menu, the fact list, the notice — are the same ones the rest of Studio needs. Defining them once, in the Studio base's own style block, is what keeps the two sections one surface instead of two that drift. A Studio Courses page therefore inherits the whole design system document (one inline stylesheet, no external CSS, the shared masthead/footer/script partials) and adds only what is its own: the breadcrumb trail back to Studio, the local-date script its deadline columns use, and its content block. Blocks a page fills here: title, breadcrumb_trail (one {% breadcrumbs %} call naming the whole trail), studio_courses_content, and everything studio/base.html exposes (head_meta, extra_styles, page_head, extra_js). The trail is drawn by the shared {% breadcrumbs %} tag, so no page here writes breadcrumb markup: it names its levels and the tag owns the nav landmark, the ordered list, the link rule and the aria-current spelling.
