The project detail and peer-review feedback forms use courses/templates/courses/_submission_page.html instead, so those two mutation surfaces share the homework form shell rather than growing a second submission layout. Writing each general project page as a standalone document is how a family drifts (the design 5a rebuild lost a navigation entry from five pages exactly that way), so this base keeps their common document in one place, the way templates/studio/base.html does it for the Studio pages, and each page fills in its own blocks. A page therefore inherits the whole design 5a document: one inline stylesheet whose first content is the shared design system partial, no external CSS, and the shared masthead / footer / script partials. Blocks a page fills: title, meta_robots, extra_styles, breadcrumbs (the li items after "Courses / "), page_head, project_content and extra_js.
