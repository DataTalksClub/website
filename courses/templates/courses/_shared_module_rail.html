One rail runs from the module page to its lessons, so moving between them keeps one frame. Progress is the signed-in reader's own: a read lesson wears the mint check, a module shows "read/total". An anonymous reader sees the same rail without any progress. A caller passing `current_lesson` gets the current-row highlight; the module page marks the module row itself as the current page. The homework row belongs to one cohort's run of the module: the reader's own delivery (`rail_cohort`/`delivery_cohort`), or the newest cohort's when none is resolved. It carries the due date, the learner's status, and -- for a learner who reads it as the stepper -- its steps: Introduction, Question N, Learning in Public, Review & submit.
