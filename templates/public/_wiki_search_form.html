{% comment %} The wiki's search box, shared by the hub and the results page so the two cannot drift apart. Without JavaScript it is a plain GET form that lands on the ranked results page (`/wiki/search?q=`). core/static/core/wiki_search.js turns it into a combobox: ranked results from `/wiki/search.json` drop down as the reader types, ↑/↓ move through them, Enter opens the highlighted one (the top result when none is), and Esc closes the list. Its rules are in public/_wiki_finder_styles.html. The field and button are the shared search bar, core/_search_row.html. Usage: {% include "public/_wiki_search_form.html" with topic_total=stats.topics %} {% include "public/_wiki_search_form.html" with topic_total=stats.topics query=query %} {% endcomment %}
