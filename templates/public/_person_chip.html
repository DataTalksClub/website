Every surface that names a person now draws them from this one partial — a book's authors, an event's speakers, an episode's guests, the homepage cards — so a reader meets the same person the same way wherever they find them, and a byline can never fall back to printing a bare source key. Pass a `person` resolved by `content.person_chip`, usually through the filter: {% include "public/_person_chip.html" with person=speaker|person_chip %} Three facts can each be missing, and each degrades on its own: * no portrait draws the person's initials in the same disc, hidden from assistive technology (the name beside it is the credit); a portrait that fails to load is swapped for the same initials by core/media_fallback.js; * no profile keeps the name as plain text rather than a link to nowhere; * the portrait itself is decorative and carries empty alternative text, because the name it sits beside is already the credit — a screen reader that heard "Portrait of Alexey Grigorev, link, Alexey Grigorev" would hear it twice.
