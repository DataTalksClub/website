{% comment %} A composed long-form body, rendered into the design system's `.prose` primitive (core/_design_system.html). It expects `sections` — the value content.article_content.prose_sections returns — and draws no styling of its own, so the book and podcast bodies can render through it when they join the system. It is the composed counterpart of public/_wiki_body.html, which renders raw projection blocks one by one: because the sections arrive already grouped, a run of source list items becomes one real list here (which also tells a screen reader how many items there are) and a heading keeps its own level rather than collapsing everything below h2 into h3. A heading keeps the fragment identifier the projected body assigned it, because those identifiers are linkable anchors that must not move. Anything this partial does not name keeps its text as a paragraph, so a block kind the projection grows later is rendered rather than dropped. `section.html` is markup the composition already put through the shared sanitizer (content.services.sanitize_rendered_html), which is why it is marked safe here — the same path templates/public/_article_faq.html uses for a recovered answer. Where a section has no such markup its plain text is drawn instead, escaped by the template as usual. Some lines here are deliberately not broken. `.prose-paragraph` keeps source line breaks and `
` keeps every character between its tags, so a newline
  written for readability inside either would become a rendered one.
{% endcomment %}
