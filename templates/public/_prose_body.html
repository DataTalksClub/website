{% load public %} {% comment %} Typed text blocks, rendered into the design system `.prose` primitive. A wiki page's body was the first (issue #179); a person's profile bio is the same shape and renders through the same partial, which is why this is not named for either. It is a separate partial from public/_body.html because that one styles its blocks with the utility classes of the older shell, which a page carrying only the design system stylesheet cannot resolve. Headings keep the identifier the source gives them, so every in-page anchor and every "#section" link into a wiki page still lands. Paragraph text keeps its own line breaks (`white-space: pre-line`), so the opening tag and the value stay on one line here. Consecutive list items arrive grouped (`prose_runs`) and draw as one real list.
