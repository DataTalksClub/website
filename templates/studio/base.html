{% comment %} The design system shell for the Studio admin surfaces (issue #179). Every public page in the system is a complete standalone HTML document with no {% extends %}, because every public page is bespoke: the homepage, a course, an episode and a wiki topic share primitives but not a layout. Studio is the opposite shape. It is ~30 near-identical staff pages — a heading, a filter bar, a dense table or a form — and 30 copies of the same document skeleton is 30 chances to drop a script, a meta robots tag or the theme-toggle data attributes, which is exactly the drift core/_site_shell_head.html was extracted to stop.
